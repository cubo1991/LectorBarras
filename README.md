# LectorBarras

App de gestión de inventario por código de barras. Ver [`SPEC.md`](./SPEC.md) para el spec completo y [`tasks/plan.md`](./tasks/plan.md) / [`tasks/todo.md`](./tasks/todo.md) para plan y tareas.

## Desarrollo

```bash
npm run dev      # servidor de desarrollo
npm run build    # build de producción
npm run lint     # eslint
npm test         # tests unitarios (Vitest)
npm run test:e2e # tests end-to-end (Playwright)
```

Este proyecto se trabaja con Spec-Driven Development — ver [`CLAUDE.md`](./CLAUDE.md).
